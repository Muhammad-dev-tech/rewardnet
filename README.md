# RewardNet

RewardNet is a PHP + MySQL web application for tracking user engagement, points, rewards, and redemption flows.

## Project phases

1. Phase 0 — Environment audit and setup verification
   - Completed
   - Confirmed XAMPP environment with PHP and MariaDB

2. Phase 1 — Application architecture and workspace scaffolding
   - In progress
   - Create the project structure, config files, and bootstrap flow

3. Phase 2 — Database design and schema
   - Add the users, rewards, and transaction tables

4. Phase 3 — Core reward logic
   - Account creation, points accrual, redemption, and validation

5. Phase 4 — Interface and dashboards
   - Admin overview and user activity UI

6. Phase 5 — QA, security hardening, and deployment prep
   - Error handling, validation, and final verification

## Local development setup

Use the XAMPP PHP binary from the local environment:

```powershell
& "C:\xampp\php\php.exe" -S 127.0.0.1:8000 -t public
```

Then browse:

```text
http://127.0.0.1:8000
```
